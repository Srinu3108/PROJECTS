## 📋 Step-by-Step: How to Show Your Projects

### Step 1: Start Your Projects

Before sharing your portfolio, make sure both projects are running:

**For EnergyPulse (ASP.NET Core):**

```bash
# Navigate to project folder
cd path/to/EnergyPulse

# Start the application
dotnet run
# OR use Visual Studio - Press F5

# Project will run at: http://localhost:5241
```

**For Farm Management System (ASP.NET Core):**

```bash
# Navigate to project folder
cd path/to/FarmManagement

# Start the application
dotnet run
# OR use Visual Studio - Press F5

# Project will run at: http://localhost:5000
```

### Step 2: Open Your Portfolio

```bash
# Option 1: Open index.html directly
open index.html

# Option 2: Use Live Server
# Install Live Server VS Code extension if not already installed
# Right-click index.html → Open with Live Server
```

### Step 3: Click "Live Demo" Button

1. Go to "Featured Projects" section on your portfolio
2. Click the 🚀 rocket icon on any project card
3. A confirmation will ask: "Make sure project is running on [URL]"
4. Click OK → Your project opens in a new tab
5. Visitor can see all features and interact with the app!
